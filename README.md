## Scope of Work

In this project, I will implement a complete DevSecOps lifecycle, which includes the following core tasks:

* **Infrastructure:** Provisioning AWS EC2 instances to host the initial environments.
* **Containerization:** Using Docker to build and package the application securely.
* **CI/CD Automation:** Building Continuous Integration and Continuous Deployment pipelines using Jenkins.
* **Security & Code Quality:** Integrating SonarQube for code quality analysis, Trivy for image and filesystem vulnerability scanning, and OWASP Dependency-Check for dependencies.
* **Orchestration:** Setting up a Kubernetes (K8s) cluster to manage the application efficiently and scalably.
* **Continuous Deployment:** Utilizing ArgoCD for deploying and managing the application directly on Kubernetes.
* **Monitoring:** Configuring Prometheus and Grafana to collect metrics, monitor application performance, and visualize cluster health.
